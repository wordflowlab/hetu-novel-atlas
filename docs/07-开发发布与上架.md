# 开发发布与上架

开发栈为Node.js25、TypeScript、React、esbuild、AJV、Node测试与Playwright。Core通过公开SDK负责固定来源与受管事务；不增加数据库服务或Rust插件。依赖版本由package-lock.json固定，SDK和色板记录摘要及许可。

先审查docs及机器合同，再实现纯领域、应用动作与视图。验证顺序为类型/合同→领域不变量→故障恢复→真实CLI/MCP全动作与Skill→Electron与视觉→最终包许可→GitHub固定Tag与Release→插件中心→正式制品下载安装。

发布前记录每个动作实际命中、全部Skill资源读取、跨作品拒绝、CAS冲突、同键恢复、停用/启用/卸载/重装及数据保留。包目录固定plugin.json、backend.mjs、index.html、view.js、view.css、skills和许可。制品sha256和目录登记一致。

发布版本不可变；修复用新版本，不覆盖既有Tag。停用/卸载不删除专业数据；宿主通用读取和导出提供退出通道。Windows无真实运行证据时不能以Mac结果代替。


## 开发者验收环境

先在河图源码仓按其开发入口构建桌面与CLI/MCP，再构建本插件。普通安装使用固定运行包，不需要这些开发工具。

| 参数 | 测试用途 |
| --- | --- |
| HETU_SOURCE | 河图源码checkout绝对目录，用于SDK测试依赖解析和开发桌面；默认相邻limecloud/hetu |
| HETU_TEST_PACKAGE | 已解压运行包的绝对目录；默认dist |
| HETU_TEST_BIN | 确切CLI/MCP/App Server二进制目录；默认宿主target/debug |
| HETU_PACKAGED_APP | 正式安装应用的可执行文件绝对路径；设置后还须明确HETU_TEST_BIN |

测试在隔离profile、插件状态和新作品中运行，不读取作者小说。真实请求和回执保留在隔离目录，公开证据只复制脱敏结果。SDK来源摘要不符、Schema或生成资源错误应修正来源后重建，不能跳过校验。
