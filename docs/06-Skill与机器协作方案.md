# Skill与机器协作

同包Skill名为hetu-novel-atlas。Codex每次经河图稳定能力发现取得当前package_sha256、capabilities_sha256及动作Schema，再通过skills.read读取方法；不要求安装独立Codex插件，不缓存旧能力假装热更新。

默认流程：固定作品范围→读取宿主文稿与设定→读取已有图鉴→按实际范围抽取有据候选→校验身份、引用与时间→CAS保存→读取多视图→作者反馈→增量修订→固定离线交付。未知结果先get_operation，不换键重复执行。

整书大于单聚合预算时按卷或明确来源批次建立多个图鉴。一个专业对象最多100来源、512KiB，默认只保存摘要与引文；不能以截断伪称整书覆盖。跨插件转交通过当前对话和各插件公开动作，正式内容仍从宿主读，不访问其他插件私有目录。

抽取与推断分开，未经确认不升级正式设定。没有证据的角色、时间和位置明确缺失。人物关系支持任意性别与题材。所需公共能力缺失时完善宿主Owner及合同，不在Skill绕过Core读写。
