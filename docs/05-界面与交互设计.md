# 界面与交互设计

插件使用宿主独立全幅工作面和单一返回入口。头部为图鉴选择、标题、状态及“让AI处理”；工具条提供人物、关系、地点、时间线、成长、器物和总览投影。默认从可读列表进入，不强制操作画布。

人物以紧凑目录和详情展示；关系用节点连线与同源可访问关系列表；地图明确“地点示意”，无位置时给地点目录；时间线可切叙事顺序和有记录的故事时间；属性及器物用分组列表。点选后查看名称、依据、摘要与投影状态，不把技术ID作标题。

Agent操作后刷新同一固定对象，未保存人工编辑不能被覆盖。保存冲突保留内容；来源错误、部分覆盖、加载、空、停用、失败、未知结果分别显示。作者可复制携带确切对象和修订的继续提示词，不要求填写JSON。

统一使用宿主Radix色板、字号与细边框。浅暗、窄窗、键盘、长名称、大关系图和恶意文本均验收。导出不引入远程资源。
